## Sobre mí

Desarrollo aplicaciones para procesos empresariales donde los datos, las reglas de negocio y la experiencia de uso deben funcionar juntos. Trabajo principalmente con **Laravel y Vue**, desde la arquitectura backend y las bases de datos hasta las interfaces e integraciones.

**Actualmente trabajo en:**
- 🔧 Módulos de contabilidad, inventarios, mantenimiento y operación con **Laravel + Vue**.
- 🔗 Integraciones entre aplicaciones web, **FileMaker** y bases de datos.

## Enfoque técnico

| Área | Lo que hago |
|---|---|
| **Arquitectura backend** | Diseño de módulos, APIs, relaciones Eloquent y validación con Laravel. |
| **Lógica de negocio** | Reglas para procesos contables, inventarios y mantenimiento con datos trazables. |
| **Frontend** | Interfaces y formularios con Vue 3, Inertia, JavaScript y React. |
| **Datos e integraciones** | MySQL, MariaDB, FileMaker y comunicación entre sistemas. |
